GranCan

Descripción
GranCan es una pagina web que nació de un pequeño negocio que tenia durante este verano, simplemente era un negocio de pasear perros, pero con los recientes eventos que sufri hicieron que le diera una vuelta a la idea, ahora GranCan es un web segura de adopción de animales, en que gente puede adoptar o dar en adopción animales de las que ya no pueden cuidar.
Ademas de que pueden subir las fotos de sus mascotas para que las vean para que la gente se animen a adoptar o contactar otros centros de adopción asociados a mi empresa.
